# Data Analytics Portfolio

A responsive one-page portfolio landing page for analytics work.

## What is included

- Modern blue analytics-dashboard visual style
- Responsive desktop and mobile layout
- Hero section with interactive-looking chart visual
- Selected work / case-study cards
- Analytics workflow snapshot
- Skills and toolkit section
- Contact CTA
- No framework or build step required

## Project cards

The featured projects are intentionally presented as editable portfolio placeholders. Replace the descriptions with your real notebooks, dashboards, datasets, or case studies as you publish them.

## GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the **main** branch and **/(root)**.
4. Save and open the generated Pages URL.

## Main file

- `index.html` — complete landing page, including all CSS and responsive styling.

## Customize

Update the links and text in `index.html`, especially the email address, project descriptions, project URLs, and GitHub profile link.
